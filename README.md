# 3bkarino Tech — Vercel + AI

موقع عربي متجاوب بالخدمات والباقات والأعمال والمقالات وأدوات حساب الحملات.

## المستشار الذكي
- `/ai-consultant`: شات لأفكار التسويق والمحتوى والمواقع وExcel.
- `/api/chat`: استدعاء حقيقي لنموذج عبر Vercel AI Gateway، بمخرجات منظمة وملخص متجدد.
- يظهر اقتراح المتابعة عند طلب تنفيذ/عرض سعر/تواصل بشري، أو بعد 6 رسائل من العميل، أو بعد 5 دقائق مع رسالتين على الأقل.
- لا ينتقل المتصفح دون اختيار العميل. يراجع العميل الملخص والإجراء المطلوب، ثم يفتح واتساب برسالة جاهزة، ويضغط إرسال في واتساب.
- رقم المتابعة الحالي من الموقع الأصلي: +20 112 012 4338.
- ملخص: النشاط، الهدف، الجمهور، الميزانية، الأفكار، والإجراء المطلوب مع العميل.
- المحادثة مؤقتة في sessionStorage للتبويب، مع زر لمسحها.
- لا توجد قاعدة بيانات لحفظ المحادثات أو إرسال آلي عبر WhatsApp Business API.
