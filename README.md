# 3bkarino Tech

Production website for **3bkarino Tech**.

## Stack
- Static RTL Arabic single-page experience generated at build time
- Vercel Functions for the AI consultant
- Vercel AI Gateway with free-provider routing
- GitHub `main` → Vercel Production

## Local build
```bash
npm install
npm run build
```

The generated site is written to `public/`.

## Environment
Copy `.env.example` for local development. Never commit real API keys.
